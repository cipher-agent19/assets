# phone-oem-telemetry-blocklist - AdGuard Home custom filter
# Scoped, conservative first version (16-Sep-2026).
# Blocks DNS for OnePlus/ColorOS/OPlus/HeyTap/NearMe/RealMe system telemetry,
# analytics, and ad networks that the stubborn OEM apps use to phone home.
# Does NOT block core Google API infra (Play/Gmail/Tasks still work).
#
# Add as a private custom-filtering-rule-list subscription in AdGuard Home:
#   URL:  https://raw.githubusercontent.com/cipher-agent19/assets/main/phone-oem-telemetry-blocklist.txt
# Refine iteratively using AdGuard's Query Log filtered by device - add domains
# the OEM apps still hit and push updates to this repo.
#
